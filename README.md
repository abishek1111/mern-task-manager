# MERN Task Manager App

A full-stack Task Manager web application built using the MERN Stack.

## Features
- Add Tasks
- Delete Tasks
- REST API Integration
- MongoDB Database
- Full Stack Architecture

## Tech Stack
Frontend: React.js  
Backend: Node.js, Express.js  
Database: MongoDB  

## How It Works
The React frontend sends API requests to the Express backend, which interacts with MongoDB to store and retrieve task data.
